# MOC: Frameworks, Toolchain & DevOps

> **TL;DR:** The **professional workflow**: code on disk (Rojo or Script Sync) in Git, pinned tools (Rokit), packages (Wally/pesde), quality gates (StyLua, selene, luau-lsp), tests, CI/CD with Open Cloud deploys, and AI agents driving Studio through the built-in MCP server. Plus the community libraries that structure game code (data, signals, cleanup, ECS, admin).
